# 绝境吴家村

以中国山区农村为背景的 Three.js 战术守村网页游戏原型，支持 PC 和移动端横屏操作。

当前版本包含山村场景、队伍部署、三波敌人进攻、自动战斗、基地焚毁、回屋补员和工程师灭火。

## 直接游玩

下载或克隆完整项目后，用支持 WebGL 的浏览器打开 `index.html`。仓库已包含构建好的 `game.js`，游玩不需要安装依赖。

## 开发与构建

安装 Node.js 后，在项目目录执行：

```sh
npm ci
npm run build
```

构建会将 `src/main.js` 及依赖打包为根目录下的 `game.js`。修改源码后重新构建，再刷新 `index.html` 查看效果。

## 基本操作

- 点击场景中的队伍或底部队伍卡片选中，再点击可移动格子部署。
- 选中守村队后点击基地，队员会直接进入房屋休整、补充兵员；休整期间点击房屋可提前迁出。
- 选中工程师后点击着火的基地，三名工程师会分散到房屋周围灭火；点击格子可调离。
- 工程师每人工作三秒减少一点焚毁速度，灭火期间暂停基地补员。灭火不会恢复房屋血量或已损坏的结构。
- 消灭全部波次且基地尚存即可胜利，无需等待灭火完成。右上角按钮可重新开局。
- PC 可按 `1` / `2` 选择守村队或工程师，按 `Esc` 取消选择。

## 文件说明

- `src/`：场景建模、渲染、移动、战斗和特效源码。
- `index.html`、`styles.css`：游戏页面与界面。
- `game.js`：可直接运行的构建产物。
- `package.json`、`package-lock.json`：开发依赖与版本锁定。

主要依赖为 Three.js，使用 esbuild 构建。场景和角色由代码生成。
