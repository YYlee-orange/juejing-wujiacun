# 绝境：吴家村

以中国山区农村为背景的 Three.js 战术守村网页游戏原型，支持 PC 和移动端横屏操作。

当前版本包含山村场景、队伍部署、三波敌人进攻、自动战斗、基地焚毁、回屋补员和工程师灭火。

美术方向记录：[UI美术规范](docs/UI美术规范.md)；选关画卷的独立方向与当前实现见 [选关界面美术与交互规范](docs/选关界面美术与交互规范.md)。

## 直接游玩

下载或克隆完整项目后，用支持 WebGL 的浏览器打开 `index.html`。仓库已包含构建好的 `game.js`，游玩不需要安装依赖。

## 云端游玩（GitHub Pages）

[在线游玩绝境吴家村](https://yylee-orange.github.io/juejing-wujiacun/)

仓库内的 `Deploy game to GitHub Pages` 工作流会在每次推送到 `main` 后自动安装依赖、构建并发布游戏。部署完成后，在仓库的 **Actions** 或 **Settings → Pages** 中打开在线游玩链接。

当前仓库已启用 GitHub Actions 发布。迁移到其他仓库时，需要在 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**。私有仓库使用 GitHub Pages 需要账号套餐支持。

本地生成与云端一致的发布文件：

```sh
npm run build:pages
```

`dist/` 仅包含游戏页面、样式、打包脚本和 `.nojekyll`，可以部署到静态网页服务。资源地址使用相对路径，支持 GitHub Pages 的项目子目录；构建时生成资源版本标记，便于更新后加载最新内容。

## 开发与构建

当前协作约定：后续改动先在本地实现、构建与验证；只有用户明确要求上传或发布后，才推送 GitHub 并更新线上版本。

安装 Node.js 后，在项目目录执行：

```sh
npm ci
npm run build
```

构建会将 `src/main.js` 及依赖打包为根目录下的 `game.js`。修改源码后重新构建，再刷新 `index.html` 查看效果。

## 基本操作

- 打开页面后先进入山村开始界面，点击中央“展开地图”或按回车进入山川画轴选关界面。
- 鼠标或单指横向拖动画卷，也可用滚轮或左右方向键浏览；点击吴家村后，墨圈绘制完成再通过云雾转场进入守村战。当前仅启用第一关，另外四处空地为后续关卡预留。
- 选关界面点击“返回”或按 `Esc` 可回到开始界面。
- 选关采用灰青布面装裱与墨线纸边，“吴家岭”为画内竖排题注，整幅装裱随拖动一起移动并铺满视口，返回键固定在黑色墨线内的右上方。村落旁的小号墨框纸签只显示地名，只有建筑参与悬停、按压和选关；顺岸流动的水纹、薄雾及缓慢淡出的鸟群都属于画中坐标。
- 点击场景中的队伍或底部队伍卡片选中，再点击可移动格子部署。
- 选中守村队后点击基地，队员会直接进入房屋休整、补充兵员；休整期间点击房屋可提前迁出。
- 选中工程师后点击着火的基地，三名工程师会分散到房屋周围灭火；点击格子可调离。
- 工程师每人工作三秒减少一点焚毁速度，灭火期间暂停基地补员。灭火不会恢复房屋血量或已损坏的结构。
- 消灭全部波次且基地尚存即可胜利，无需等待灭火完成。
- PC 可按 `1` / `2` 选择守村队或工程师，按 `Esc` 取消选择。
- 下方小队面板仅在选中时显示。可点击场景中的队伍或旗帜选队；点击面板可取消选择。
- 点击右上角暂停图标或按空格打开暂停菜单，菜单中可继续游戏、重新开始或回到开始界面。
- 点击关闭图标、菜单外空白处或按 `Esc` 可收起暂停菜单；弹窗关闭后恢复战斗。
- 开始游戏、重新开始和返回开始界面统一使用对角云雾转场，画面完全遮住后才切换。

## 文件说明

- `src/`：场景建模、渲染、移动、战斗和特效源码。
- `index.html`、`styles.css`：游戏页面与界面。
- `game.js`：可直接运行的构建产物。
- `package.json`、`package-lock.json`：开发依赖与版本锁定。
- `assets/`：彩色人物头像、山川长卷与村落符号、楷体子集及字体许可。来源与提示词见 [UI资源记录](docs/UI资源记录.md) 和 [选关界面资源记录](docs/选关界面资源记录.md)。

主要依赖为 Three.js，使用 esbuild 构建。场景和角色由代码生成。
